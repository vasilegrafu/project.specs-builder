| Rule | Value |
|---|---|
| the grid | one column of content, whose cards wrap in rows, each at least 220px wide |
| the breakpoints | 640px: below it, the header's pages move to a row of their own, headings shrink, tables scroll in their own box |
| the page's width | 1120px at most, centred; the header, the home page's opening and the footer run the whole width |
| the page's margins | 24px each side; 16px below 640px |
| a form | its fields no wider than 420px, one under another, each label above its field |
