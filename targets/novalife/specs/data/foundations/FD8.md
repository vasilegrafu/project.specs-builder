name: Patterns
---

| Pattern | Rule | Example |
|---|---|---|
| a failure | a red message above the form: what failed, that nothing changed, the next step; what was written is kept | Your booking couldn't be made, and nothing is booked. Please try again. |
| a refusal of a field | the field's red edge, and the reason in a line of red text beneath it | Date of birth can't be in the future. |
| a success | a green message where the action was, or the next screen | Saved. Visitors now see the new words. |
| an empty list | a plain message that says there is nothing, and the way to add the first | You have no bookings yet. |
| loading | the button that started it says what it is doing, and cannot be pressed twice | Booking… |
| what cannot be undone | a dialog that names the thing, with the action and a way to keep it | Cancel First consultation with Dr. Lee on Friday, November 20, 2026, 10:00 AM? |
| money | US dollars, no cents where there are none | $120 |
| dates and times | as written in the United States, the day of the week first | Friday, November 20, 2026, 10:00 AM |
| colour | never the only sign: the words say whether it failed or was done | |
