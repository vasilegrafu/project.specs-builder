---
id: R15
name: Email before text
priority: should
serves: G1, G2, G3, G4
depends on: R13
---

Where a customer can be reached by both email and text message, the website shall send the request by email.

## Accepted when

- R15.1 Given a customer with an email address and a mobile number, when a request is due, then it goes by email and no text is sent.
- R15.2 Given a customer with only a mobile number, when a request is due, then it goes by text message.
- R15.3 Given a customer with only an email address, when a request is due, then it goes by email.
