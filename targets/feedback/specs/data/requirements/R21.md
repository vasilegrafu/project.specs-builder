---
id: R21
name: No request lost to downtime
priority: must
serves: G1, G2, G3, G4
depends on: R13
---

If the website was down when a request fell due, then the website shall send that request once it is back.

## Accepted when

- R21.1 Given a request that fell due on 3 March while the website was down, when it is back on 4 March, then the customer receives that request on 4 March.
- R21.2 Given a request that fell due while the website was down, when it is back, then the customer receives it once.
- R21.3 Given a customer who opted out while the website was down, when it is back, then no request is sent to them.
