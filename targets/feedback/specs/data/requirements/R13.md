---
id: R13
name: Ask after a purchase
priority: must
serves: G1, G2, G3, G4
---

When a customer's order has been delivered, the website shall send them one request for feedback holding a link to the feedback page.

## Accepted when

- R13.1 Given an order delivered on 3 March, when the delivery is known, then the customer receives one request holding a link to the feedback page.
- R13.2 Given an order for three products, when it is delivered, then the customer receives one request for the order, not three.
- R13.3 Given a customer the website has no way of reaching, when their order is delivered, then no request is sent and nothing else changes.
- R13.4 Given a request that cannot be delivered, when the website tries to send it, then the failure does not stop any other customer's request.
