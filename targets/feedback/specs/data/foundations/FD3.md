name: Density and spacing
---

| Rule | Value |
|---|---|
| The spacing scale | 4, 8, 12, 16, 20, 24, 32, 48px |
| Inside a button | 10px above and below, 18px at the sides; a small one 6px and 12px |
| Inside a field | 9px above and below, 12px at the sides |
| Inside a card | 32px; 24px and 20px on a phone |
| Inside a feedback card or panel | 20px |
| Between fields | 20px |
| Between feedback cards | 12px |
