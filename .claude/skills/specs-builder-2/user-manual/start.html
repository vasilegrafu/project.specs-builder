Part 2: Working with Claude

Three ways to start

Tell Claude Code what you have. You can mix all three within one specification.

Say what you have

Ask for what you want. Naming the skill, specs-builder-2, makes sure it's the one that answers.

You have an idea. Claude asks for the goal, writes it up complete, then asks what else it needs to know. This is called write-ask.

You have only a name or a rough goal. The skill asks, and writes from your answers. This is ask-write.

You have something that already exists. Claude reads the website, documents or program code, and notes where each fact came from. This is called reverse-engineering: working out the description from the finished thing.

Four rules that always hold

  • It completes the behaviour, but never invents a fact. It adds the cases you did not mention and marks each one as an addition until you confirm it. Numbers, laws and facts about your users are asked, never guessed.
  • It writes only what is needed. A section with nothing to say is left out.
  • It says what and why, never how. A requirement is behaviour someone outside the product can observe.
  • You decide. What the skill proposes is yours only once you confirm it.
