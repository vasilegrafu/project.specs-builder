Part 1: From zero

What is Claude Code?

You'll write specifications by having a conversation. This page explains who with, and where.

An assistant that works on your files

Claude is an AI made by Anthropic. You may have used it, or something like it, in a chat window. Claude Code is the version that can work directly on the files on your computer: read them, write them, and run small programs. You tell it what you want in ordinary language, and it does the work and shows you.

It's a bit like having a capable colleague at the next desk. You don't need to know how they do the job, but you do need to say clearly what you want, and to check what comes back.

Where you talk to it

Claude Code runs in a terminal: a plain window where you type instead of clicking. Every computer has one. On Windows it's called PowerShell or Terminal, and on a Mac it's called Terminal. It can look unfriendly, but you only need it to start Claude. After that, you just type sentences. Claude Code also comes as a desktop app, and works inside some code editors, if you'd rather not use a terminal.

What a skill is

On its own, Claude knows a great deal but has no fixed way of doing a job. A skill is a folder of instructions that teaches it one job properly, the way a new colleague might be given a procedure.

specs-builder-2 is the skill that teaches Claude to write and look after specifications. Saying "Use specs-builder-2" makes sure it's the skill that answers.

Is it safe to try?

Yes. Claude asks before it does things, depending on how you've set it up, and you can say no. Everything it writes stays in one folder on your computer. And there's a safety catch, as you'll see: a change that would break the specification is refused whole.

What you do need to do is read what it writes. It's quick and capable, but it can misunderstand you. You're the one who knows your business.

What you need

Claude Code, Python and a browser. SETUP.md lists them and how to check them. To only read a specification someone sent you, you need just Python and a browser.
