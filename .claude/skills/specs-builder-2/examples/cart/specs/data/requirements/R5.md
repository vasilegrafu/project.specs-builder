When a page applies a code, the cart shall read it without the spaces around it and in capitals, and apply it in place of any code before it, where it is four to twelve letters and digits, a code the shop runs, and not past its date.

## Accepted when

- R5.1 Given a cart of the Hush 700 at €299.00, when "welcome10" is applied, then WELCOME10 is applied, €29.90 is taken off and the total is €269.10.
- R5.2 Given WELCOME10 is applied, when AUTUMN5 is applied, then AUTUMN5 alone is applied.
- R5.3 Given "no spaces" is typed, when it is applied, then the cart answers 422 with "a code is 4 to 12 letters and digits" and the code applied before stays.
- R5.4 Given "NOPE1" is typed, when it is applied, then the cart answers 422 with "that code is not known".
- R5.5 Given AUTUMN5 after 30 November 2026, when it is applied, then the cart answers 422 with "AUTUMN5 expired on 30 November 2026".
- R5.6 Given AUTUMN5 applied on 29 November 2026, when the cart is checked out on 2 December 2026, then AUTUMN5 still takes its 5 percent off.
