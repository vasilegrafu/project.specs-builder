id: A6
name: Write an amount as its country writes it
kind: read
surface: vatkit.money(value, country=None)
shows: R6, R8
about: B1, B7
---

What a program calls to write an amount on an invoice as the customer's member state writes it.

## Who may call

| Caller | May | Else |
|---|---|---|
| U1, U3: any program that imports vatkit | write any amount for any country, or none | nothing is refused for who calls: vatkit has no keys and no accounts |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| value | argument | a Decimal, a whole number or a string of one: "1234.5" | yes | never a float, never below zero, B1, B7, R8 |
| country | argument | string: two letters; or None | no | DE, AT, IT and ES write 1.234,50 €; NL €1.234,50; FR 1 234,50 € with a narrow space; any other, or none, €1,234.50, R6 |

## Answers

| Status | When | Holds |
|---|---|---|
| returns | the amount is taken | the amount to the cent, half up, as text in that country's way: "1.234,50 €" |

## Fails

| Status | When | Says |
|---|---|---|
| raises BadAmount | the amount is a float, is not a number, or is below zero | "1234.5: give a Decimal, a whole number or a string, never a float" |

## Limits

| What | Is |
|---|---|
| Version | the major version changes only when this function's name or what it takes changes (E70) |
| Idempotent | yes: the same call answers the same within one release |
