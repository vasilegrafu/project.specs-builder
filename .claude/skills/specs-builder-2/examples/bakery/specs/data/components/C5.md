---
id: C5
name: Button
---

What a person presses to do something or go on. One main button to a view; anything beside it is quiet.

## Variants

| Variant | When |
|---|---|
| main | the one main action of a view |
| quiet | an action beside the main one |
| under the pointer | the pointer over a main button |
| keyboard focus | the keyboard on a button |
| sending | the action has been pressed and its answer is awaited |
| disabled | the action cannot be taken now |
| pressed | the button is held down |

## Rules

- One main button to a view.
- Fills the width at a form's foot on a phone.
- Sending keeps its width, so that nothing jumps.
