name: Form field
---

One thing a person enters, with its label, a hint where it helps, and what to fix if it is refused.

## Parts

| # | Part | Kind | What it shows and does | States | Heard as | Component | Shows | About | Asks | Leads to |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | The label | text | Names what is entered. |  | the field's name |  |  |  |  |  |
| 2 | The control | field | Where it is entered: a box, a list or a date. |  | the field, and what is in it |  |  |  |  |  |
| 3 | The hint | text | A line that helps, where one does. |  | read with the field |  |  |  |  |  |
| 4 | What to fix | message | Says what to fix, under the control. | refused only | read with the field |  | R4 |  |  |  |

## Variants

| Variant | When |
|---|---|
| default | waiting for what the person enters |
| keyboard focus | the keyboard is on it |
| refused | what was entered was refused: it says what to fix |
| disabled | the form cannot be sent, or is being sent |
| under the pointer | the pointer over the control |

## Rules

- The label stands above the control and never leaves it.
- A refused control says what to fix under it; colour never says it alone.
- Optional is said in the label, not the hint.
