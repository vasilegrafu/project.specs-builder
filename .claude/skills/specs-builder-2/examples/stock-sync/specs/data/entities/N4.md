name: Report
---

What a run says of the night: its outcome, how many SKUs changed, which are low and which out, which the feed no longer carries, and each change.

## Fields

| Field | Meaning | From |
|---|---|---|
| head | the time in UTC and the outcome: done, or a dry run with nothing written |  |
| changed | how many SKUs changed |  |
| low | the SKUs at three or fewer and more than none |  |
| out | the SKUs at none |  |
| not in the feed | the SKUs the shop sells and the feed no longer carries, each with the shop's quantity |  |
| changes | each SKU written, as "SKU: before → after" |  |
