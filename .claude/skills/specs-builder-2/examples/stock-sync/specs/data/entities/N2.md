The supplier's list of the stock it holds, one row per SKU with its quantity and the time the list was made, rebuilt every night at 01:00.

## Fields

| Field | Meaning | From |
|---|---|---|
| sku | the product's code, as the catalogue has it |  |
| quantity | a whole number of none or more |  |
| as_of | when the supplier made the list; the same on every row |  |
