While a run is going, the stock sync shall hold any other run off, and take over a lock left behind for more than six hours.

## Accepted when

- R7.1 Given a run that started at 02:31 and is still going, when another is started by hand at 02:40, then the second writes nothing, says "another run holds the lock" with where the lock is, and ends with exit 4.
- R7.2 Given a run that ended, whatever its outcome, when the next starts, then the lock is free.
- R7.3 Given a lock left by a run that died 7 hours before, when the next run starts, then it takes the lock over and runs.
- R7.4 Given a lock left 5 hours before and no run going, when the next run starts, then it is held off, and the operator removes the lock as the runbook says.
