When it is 02:30 in Berlin, the stock sync shall start one run that brings the shop's stock in line with the supplier's feed.

## Accepted when

- R1.1 Given the host is up, when the clock in Berlin reaches 02:30, then a run starts by 02:35 and its first line is in the night's log.
- R1.2 Given the host was down from 02:00 to 06:10, when it is up again, then the run of that night starts and the night is not lost.
- R1.3 Given a run still going 45 minutes after its start, when the 45th minute passes, then it is stopped, and the morning hears of it as a run that stopped, R6.
- R1.4 Given the summer's time and the winter's, when the night comes, then the run starts at 02:30 by the clock in Berlin in both.
