---
id: R3
name: Refuse a feed that cannot be right
priority: must
serves: G1, G2
enforces: B1, B8
from: S2, stock_sync.py, the reading of the feed, and its tests; S3, the runbook's exit 2
---

If the feed has no rows, lacks its SKU, its quantity or the time it was made, holds a quantity that is not a whole number of none or more, or was made more than 36 hours before the run, then the stock sync shall refuse the run, change nothing, and say why.

## Accepted when

- R3.1 Given a feed of the header alone, when it is read, then the run is refused with "the feed has no rows" and ends with exit 2.
- R3.2 Given a feed that does not say when it was made, when it is read, then the run is refused, and the reason names as_of.
- R3.3 Given a quantity of "forty" on line 12, when it is read, then the run is refused with "line 12: quantity 'forty' is not a whole number".
- R3.4 Given a quantity of -2 on line 7, when it is read, then the run is refused with "line 7: quantity -2 is below zero".
- R3.5 Given a feed made 37 hours before the run, when it is read, then the run is refused with the time it was made and "older than 36 hours"; one made 35 hours before is read.
- R3.6 Given any of these refusals, when the run ends, then no SKU of the shop has changed and the morning is mailed with the reason, R6.
