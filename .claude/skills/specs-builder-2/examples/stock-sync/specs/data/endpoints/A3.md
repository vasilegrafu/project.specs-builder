id: A3
name: Run from a feed file
kind: action
surface: python stock_sync.py --feed FILE
shows: R5, R7, R9
about: B1, B8
---

What the operator runs to sync from a feed saved by hand, in place of the supplier's address.

## Who may call

| Caller | May | Else |
|---|---|---|
| U2, the operator on call | run the job from a feed file, as the job's user | a file that cannot be read stops the run with exit 5, R9 |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| FILE | argument | a file's path | yes | a feed of sku, quantity and as_of, held to every check the fetched feed is held to, B1, B8, R9 |

## Answers

| Status | When | Holds |
|---|---|---|
| exit 0 | the file was read and every change written | as a night's run |
| exit 1 | the file and the shop's stock agree | "nothing to do" |

## Fails

| Status | When | Says |
|---|---|---|
| exit 2 | the file is empty, out of shape or stale, or would change more than half the SKUs | "the feed was refused:" and the reason, in the log and in a mail |
| exit 3 | the catalogue refused a write | the SKU, in the log and in a mail |
| exit 4 | another run holds the lock | "another run holds the lock" |
| exit 5 | the file does not exist or cannot be read | the reason, in the log and in a mail |
