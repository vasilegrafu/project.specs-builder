What an integrator calls once to be told of every move: an https address, the events it wants, and the secret that signs each delivery, shown this once.

## Who may call

| Caller | May | Else |
|---|---|---|
| U1, a key with the scope webhooks | subscribe for its own account | 403 for U2, whose key never has the scope webhooks, B6 |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| url | body | string, an address that starts with https:// | yes | https only; http is refused, R7 |
| events | body | a list of one or two of shipment.status.changed and shipment.delivery.attempted | yes | at least one, and only those two, R7 |

## Answers

| Status | When | Holds |
|---|---|---|
| 201 | the address is https and each event is one Parcelpost sends | the subscription: its id, WH and eight hexadecimal characters; the address; the events; the secret; and active |

## Fails

| Status | When | Says |
|---|---|---|
| 401 | no key, or one not known or revoked | {"detail": {"error": "no API key: send Authorization: Bearer <key>"}} , or that the key is not known or has been revoked |
| 403 | the key lacks the scope webhooks | {"detail": {"error": "the key lacks the scope webhooks"}} |
| 422 | an event is not one Parcelpost sends | {"detail": {"error": "no such event: shipment.picked.up", "field": "events"}} |
| 422 | the address is not https, or no event is given | the field and why, as the schema refuses it |

## Limits

| What | Is |
|---|---|
| Idempotent | no: each call makes a subscription, with a secret of its own |
| Version | v1, in the path |
