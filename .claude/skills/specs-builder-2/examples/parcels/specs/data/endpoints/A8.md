What an integrator calls to see whether each subscription is still being delivered to: active or paused, and its failures in a row.

## Who may call

| Caller | May | Else |
|---|---|---|
| U1, a key with the scope webhooks | list its own account's subscriptions | 403 for a key without webhooks, B6 |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| Authorization | header | Bearer and the key | yes | a key with the scope webhooks, B6 |

## Answers

| Status | When | Holds |
|---|---|---|
| 200 | always, for the account's own subscriptions | each subscription: its id, address and events, whether it is active, and its failures in a row; never its secret |

## Fails

| Status | When | Says |
|---|---|---|
| 401 | no key, or one not known or revoked | {"detail": {"error": "no API key: send Authorization: Bearer <key>"}} , or that the key is not known or has been revoked |
| 403 | the key lacks the scope webhooks | {"detail": {"error": "the key lacks the scope webhooks"}} ; the description lists no 403 here |

## Limits

| What | Is |
|---|---|
| Size | every subscription of the account, on one page |
| Idempotent | yes |
| Version | v1, in the path |
