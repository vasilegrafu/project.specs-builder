When an integrator subscribes an https address to one or both of the events Parcelpost sends, Parcelpost shall keep the subscription, active, and answer the secret that signs its deliveries, this once.

## Accepted when

- R7.1 Given a key with the scope webhooks, when an https address is subscribed to shipment.status.changed, then the answer is 201 with an id of WH and eight hexadecimal characters, the address, the event, the secret, and active.
- R7.2 Given an address that starts with http://, when it is subscribed, then the answer is 422 and no subscription is made.
- R7.3 Given the event shipment.picked.up, when it is subscribed to, then the answer is 422 and says there is no such event.
- R7.4 Given an account's subscriptions, when they are listed, then each is answered with its address, its events, whether it is active and its failures in a row, and none with its secret.
- R7.5 Given a subscription, when it is stopped, then the answer is 204 and it is listed no more.
- R7.6 Given a key without the scope webhooks, when a subscription is made, listed or stopped, then the answer is 403 and names webhooks.
