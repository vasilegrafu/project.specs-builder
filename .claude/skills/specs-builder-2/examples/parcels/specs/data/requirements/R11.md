id: R11
name: A test key's shipments are never collected
priority: must
serves: G3
from: S2, auth.py:17 and app.py:146; S5, README.md:16

Where a key is a test key, Parcelpost shall mark the labels of its shipments TEST, say so in the label's answer, and never have its shipments collected.

## Accepted when

- R11.1 Given a test key, when a label is produced with it, then the answer says test is true and the PDF says TEST.
- R11.2 Given a live key, when a label is produced with it, then the answer says test is false.
- R11.3 Given a labelled shipment of a test key, when a week passes, then it is still labelled.
