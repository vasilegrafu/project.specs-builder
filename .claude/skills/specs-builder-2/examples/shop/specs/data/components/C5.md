Whether a product can be bought, in three words.

## Variants

| Variant | When |
|---|---|
| default | more than three left |
| few left | three or fewer left |
| out of stock | none left: Add to cart is disabled beside it |

## Rules

- Green, amber, red: the colours of the foundations, never alone, always with the words. (foundations)
- The number behind "a few" is never shown.
