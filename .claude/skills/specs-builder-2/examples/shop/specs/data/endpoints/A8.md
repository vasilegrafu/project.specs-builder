---
id: A8
name: Move an order
kind: write
surface: PATCH /api/v1/orders/{number}
shows: R13, R14
about: B3, B4, N3
---

What the admin's Mark as paid, Mark as shipped, Mark as delivered and Cancel the order call: the order's next status, with a note.

## Who may call

| Caller | May | Else |
|---|---|---|
| U3, the admin | move any order forward, or cancel it while placed or paid | 403 for a customer's session, B4, R14 |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| number | path | string, VL-1047 | yes | the order's number, N3 |
| status | body | string: paid, shipped, delivered, cancelled | yes | the next status from where the order is, B3 |
| note | body | string | no | kept on the order with who and when, R13 |

## Answers

| Status | When | Holds |
|---|---|---|
| 200 | the move is one the status allows | the order, moved |

## Fails

| Status | When | Says |
|---|---|---|
| 403 | the caller is not the shop's staff | {"error": "the caller is not the shop's staff"} |
| 409 | the order cannot move to that status from where it is | {"error": "the order cannot move to that status from where it is"} , which the admin's order page shows above the actions |

## Limits

| What | Is |
|---|---|
| Idempotent | no: the same move twice is refused the second time |
| Version | v1, in the path |
