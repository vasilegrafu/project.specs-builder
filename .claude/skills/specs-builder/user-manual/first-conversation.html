Part 2: Working with Claude

Your first conversation

You don't need to prepare anything. Here's what a first session looks like, from opening the window to reading the result.

Before you start

You need Claude Code, Python and a browser. SETUP.md says how to get them and how to check them. If someone has set this up for you, you need only the steps below.

Step by step

  1. Open a terminal in your project folder. On Windows, open the folder in File Explorer, click the address bar, type powershell and press Enter. On a Mac, open Terminal and type cd, a space, then drag the folder in and press Enter.
  2. Start Claude Code. Type claude and press Enter. You'll get a prompt where you can type sentences.
  3. Say what you want, and start with the skill's name.
  4. Say what should get better. This comes first. Every requirement has to serve a goal, and only you can set one. If you've never counted something, say so.
  5. Answer its questions. It asks what it can't know. "I don't know yet" is a fine answer: it becomes an open question.
  6. Choose the look. Before drawing anything properly, it asks about your brand, what you like and the theme. If you have nothing to go on, it offers directions to choose from.
  7. Open what it made. Ask it to open the application, and it appears in your browser.
  8. Read, and say what's wrong. Go back to Claude and say it in your own words.

A first session

What just happened

You said what you wanted and answered what only you could, and you got a first version. Then you corrected it by talking. That's the whole way of working: react to something real, not a blank page.

How to carry on

Coming back later

Everything is in the folder, not in the conversation. So you can close the window, come back next week, start claude in the same folder and say "Use specs-builder. What's still open?". You can open the website at any time without Claude at all.
