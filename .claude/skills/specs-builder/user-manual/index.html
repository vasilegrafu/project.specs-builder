specs-builder user manual

Start here

This manual assumes you know nothing about specifications, graphs or Claude Code. If you can use a website, you can follow it.

What this is, in three sentences

Before anyone builds a website or an app, someone has to say what it should do. That description is called a specification, and it's usually a long document that goes out of date. specs-builder helps you write one with an AI assistant, keeps it as a set of small connected facts rather than one long document, and lets you read it in your browser like a small website.

How to read this manual

Read Part 1 first, in order. It takes about twenty minutes and needs nothing installed. After that, dip in wherever you like.

Everything is shown on one example, Voltline, a made-up online shop. You'll pretend you own it. One tiny rule from that shop, a cart holds up to five of a product, runs through the whole manual: first to explain the idea, then to show you around, and finally to be changed, for real, from start to finish.
