name: Name the SKUs the feed no longer carries
priority: should
serves: G1

When a run ends, the stock sync shall list in the night's report every SKU the shop sells that the feed does not carry, with the shop's quantity of each, and leave that quantity as it is.

## Accepted when

- R11.1 Given the shop sells LT-ZEN-12 at 6 and the feed no longer carries it, when the run ends, then the report lists "LT-ZEN-12: 6, not in the feed", and its quantity stays 6.
- R11.2 Given 12 such SKUs and nothing else to report, when the run ends, then the mail comes with the 12, R6.
- R11.3 Given every SKU of the shop is in the feed, when the run ends, then the report says "none" under that heading.
