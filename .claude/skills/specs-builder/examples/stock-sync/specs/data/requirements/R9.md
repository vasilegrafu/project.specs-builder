When the operator gives a feed file, the stock sync shall read it in place of the supplier's address and hold it to every check the fetched feed is held to.

## Accepted when

- R9.1 Given a feed file saved from the supplier this morning, when the operator runs with it, then the run reads it, nothing is fetched, and it goes on as a night's run.
- R9.2 Given a feed file made two days before, when the operator runs with it, then the run is refused as stale, as the fetched feed would be.
- R9.3 Given a file that does not exist, when the operator runs with it, then the run stops, says so, and ends with exit 5.
