---
id: R8
name: A dry run
priority: should
serves: G1
enforces: B2
from: S2, stock_sync.py, the option --dry-run; S3, the runbook's "Changed too much"
---

When the operator asks for a dry run, the stock sync shall read the feed, compare it with the shop's stock and print the report of what would change, and write nothing to the catalogue and mail nothing.

## Accepted when

- R8.1 Given a feed that changes 23 SKUs, when the operator runs a dry run, then the report is printed with "dry run, nothing written" and the 23 changes, the catalogue is unchanged, and the run ends with exit 0.
- R8.2 Given a stock take that changes 640 of 1,000 SKUs, when the operator runs a dry run, then the report of the 640 is printed with a line that says the guard would refuse it, R4.
- R8.3 Given a feed refused for its shape or its age, when the operator runs a dry run, then the reason is printed and no mail is sent.
