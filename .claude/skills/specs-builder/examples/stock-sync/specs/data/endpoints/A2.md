What the operator runs before a stock take, or to see what a night would do: the report of what would change, with nothing written and nothing mailed.

## Who may call

| Caller | May | Else |
|---|---|---|
| U2, the operator on call | read what a run would change, as the job's user | a run without the tokens stops with exit 5, and mails nothing, R8 |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| --dry-run | argument | flag | yes | nothing is written to the catalogue and nothing is mailed, R8 |
| --feed | argument | a file's path | no | a feed file in place of the supplier's, R9 |

## Answers

| Status | When | Holds |
|---|---|---|
| exit 0 | some SKUs would change | the report, printed, headed "dry run, nothing written", with each change; where more than half would change, a line that says the guard would refuse it |
| exit 1 | nothing would change | "nothing to do" |

## Fails

| Status | When | Says |
|---|---|---|
| exit 2 | the feed could not be fetched, or is empty, out of shape or stale | the reason, printed; no mail |
| exit 4 | another run holds the lock | "another run holds the lock"; no mail |

## Limits

| What | Is |
|---|---|
| Idempotent | yes: it changes nothing |

## Example

```text
$ python stock_sync.py --dry-run
Stock sync 2026-10-11 09:12 UTC: dry run, nothing written
2 SKU(s) changed
1 low (at or under 3): AC-VLT-65
0 out of stock: none

AC-VLT-65: 5 → 3
LT-NMD-13: 12 → 9
```
