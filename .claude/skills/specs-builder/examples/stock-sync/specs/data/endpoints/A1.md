What the timer starts every night and the operator runs by hand: one run, from the fetch of the feed to the morning mail.

## Who may call

| Caller | May | Else |
|---|---|---|
| U1, the timer | start the night's run, as the host's job user, with the two tokens in its environment | -- |
| U2, the operator on call | start a run by hand from the runbook, as the job's user | a run without the tokens in its environment stops with exit 5, R6 |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| SUPPLIER_FEED_TOKEN | environment | text | yes | the supplier's token, from the host's file, never from the job's |
| CATALOGUE_TOKEN | environment | text | yes | the catalogue's token, likewise |

## Answers

| Status | When | Holds |
|---|---|---|
| exit 0 | the feed was read and every change written | "done: N SKU(s) changed" in the log; the report kept, and mailed where anything is low, out or no longer in the feed |
| exit 1 | the feed and the shop's stock agree | "nothing to do" in the log; mailed only where anything is low, out or no longer in the feed |

## Fails

| Status | When | Says |
|---|---|---|
| exit 2 | the feed could not be fetched in three tries, was empty, out of shape or stale, or would change more than half the SKUs | "the feed was refused:" and the reason, in the log and in a mail whose subject says FAILED; the shop's stock is as it was |
| exit 3 | the catalogue refused a write | "the run stopped: the catalogue refused" and the SKU, in the log and in a mail; the writes before it stay |
| exit 4 | another run holds the lock, younger than six hours | "another run holds the lock" and where it is, in the log and in a mail |
| exit 5 | any other stop: the catalogue does not answer with the shop's stock, a token is missing, the run is stopped at 45 minutes | the reason, in the log and in a mail whose subject says FAILED |

## Limits

| What | Is |
|---|---|
| Rate | one run at a time, B5 |
| Idempotent | yes: a second run with the same feed finds nothing to do, R5 |

## Example

```text
$ python stock_sync.py
2026-10-10 02:31:04 INFO starting: feed https://feed.nordkabel.example/voltline/stock.csv
2026-10-10 02:41:09 INFO done: 23 SKU(s) changed
$ echo $?
0
```
