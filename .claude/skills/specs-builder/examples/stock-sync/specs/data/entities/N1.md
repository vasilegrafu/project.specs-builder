name: Run
---

One pass of the job, started by the timer or by the operator: it takes the lock, reads the feed, compares, writes, reports, and gives the lock back.

## Fields

| Field | Meaning | From |
|---|---|---|
| started | when it started, in the log's first line |  |
| how | the night's, a dry run, or from a feed file |  |
| outcome | done, nothing to do, refused, stopped or held off, by its exit code |  |
| changes | the SKUs written, each with its number before and after |  |

## Lifecycle

| State | Event | Guard | Effect | Next |
|---|---|---|---|---|
| started | another run holds a lock younger than six hours | -- | the log says so; the morning is mailed | held off |
| started | the lock is free, or older than six hours | -- | the lock is taken | reading |
| reading | the feed is fetched or read from a file, and passes its checks | -- | -- | comparing |
| reading | the feed cannot be fetched in three tries, or fails a check | -- | the morning is mailed | refused |
| comparing | nothing differs | -- | -- | nothing to do |
| comparing | more than half the shop's SKUs would change | not a dry run | the morning is mailed | refused |
| comparing | some SKUs differ | a dry run | the report is printed; nothing is written or mailed | done |
| comparing | some SKUs differ | not a dry run | -- | writing |
| writing | every write is taken | -- | the report is kept, and mailed where anything is low | done |
| writing | the catalogue refuses a write | -- | what was written stays; the morning is mailed | stopped |
