What a shop's program calls to find its shipments: newest first, fifty to a page, kept to a status or to its own reference.

## Who may call

| Caller | May | Else |
|---|---|---|
| U1 or U2, a key with shipments:read | list its own account's shipments | 403 for a key without shipments:read, B6 |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| status | query | string: one of the eight statuses of N1 | no | only shipments in that status, R5 |
| reference | query | string | no | only shipments with that reference of the sender's, R5 |
| page | query | integer from 1 | no | fifty to a page; the first where none is given, R5 |

## Answers

| Status | When | Holds |
|---|---|---|
| 200 | always, for the account's own shipments | the page's shipments, newest first, each as A3 answers it; the page; and how many there are in all |

## Fails

| Status | When | Says |
|---|---|---|
| 401 | no key, or one not known or revoked | {"detail": {"error": "no API key: send Authorization: Bearer <key>"}} , or that the key is not known or has been revoked |
| 403 | the key lacks shipments:read | {"detail": {"error": "the key lacks the scope shipments:read"}} |
| 200 | nothing matches | no item, and a total of 0 |

## Limits

| What | Is |
|---|---|
| Size | fifty shipments to a page |
| Idempotent | yes |
| Version | v1, in the path |
