What a shop's program calls before the parcel is handed over: the label, an A6 PDF with the barcode the courier scans, the same every time.

## Who may call

| Caller | May | Else |
|---|---|---|
| U1, a key with the scope labels | produce the label of its own account's shipment | 403 for U2, whose key may only read, B6 |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| shipment_id | path | string, PP and twelve digits | yes | a shipment of the account's that is not cancelled, B9 |

## Answers

| Status | When | Holds |
|---|---|---|
| 200 | the shipment is not cancelled | the shipment's id, the address of the PDF, the format A6, and whether the key is a test key; the first call moves the shipment to labelled and tells the subscribers |

## Fails

| Status | When | Says |
|---|---|---|
| 401 | no key, or one not known or revoked | {"detail": {"error": "no API key: send Authorization: Bearer <key>"}} , or that the key is not known or has been revoked |
| 403 | the key lacks the scope labels | {"detail": {"error": "the key lacks the scope labels"}} |
| 404 | no shipment has the id, or it is another account's | {"detail": {"error": "no shipment has that id"}} |
| 409 | the shipment is cancelled | {"detail": {"error": "the shipment is cancelled; it has no label"}} |

## Limits

| What | Is |
|---|---|
| Idempotent | yes: a second call answers the same label and moves nothing |
| Version | v1, in the path |

## Example

```http
POST /v1/shipments/PP-000000000001/label
Authorization: Bearer <key>
```

```http
200 OK
Content-Type: application/json

{"id": "PP-000000000001", "label_url": "https://labels.parcelpost.example/PP-000000000001.pdf", "format": "A6", "test": true}
```
