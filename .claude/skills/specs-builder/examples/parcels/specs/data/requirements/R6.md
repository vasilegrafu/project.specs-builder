If a call comes with no key, with a key that is not known, with a key that lacks the scope the call needs, or names another account's shipment or subscription, then Parcelpost shall refuse it: 401 for the key, 403 naming the scope, and 404 for what is not the account's.

## Accepted when

- R6.1 Given a call with no Authorization header, when it is made, then the answer is 401 and says to send Authorization: Bearer and the key.
- R6.2 Given a revoked key, when any call is made with it, then the answer is 401 and says the key is not known or has been revoked.
- R6.3 Given a key with shipments:read alone, when it registers a shipment, then the answer is 403 and says the key lacks the scope shipments:write.
- R6.4 Given a shipment of another account, when its id is asked for, then the answer is 404, as for an id no shipment has.
- R6.5 Given a subscription of another account, when it is stopped, then the answer is 404 and it is not stopped.
