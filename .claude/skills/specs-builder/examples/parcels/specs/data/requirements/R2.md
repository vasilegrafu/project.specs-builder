When an integrator asks for the label of a shipment that is not cancelled, Parcelpost shall answer the address of its A6 PDF with the barcode, the same label every time it is asked for.

## Accepted when

- R2.1 Given a created shipment, when its label is asked for, then the answer holds the address of an A6 PDF, the shipment is labelled, and its events end with Label produced.
- R2.2 Given a labelled shipment, when its label is asked for again, then the same address is answered and no event is added.
- R2.3 Given a cancelled shipment, when its label is asked for, then the answer is 409, says that the shipment is cancelled and has no label, and no label is made.
- R2.4 Given a key without the scope labels, when a label is asked for, then the answer is 403 and names labels.
