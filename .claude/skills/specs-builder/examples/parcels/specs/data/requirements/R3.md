When an integrator cancels a shipment the courier does not yet have, Parcelpost shall mark it cancelled, so that its label is void, and tell the subscribers.

## Accepted when

- R3.1 Given a created shipment, when it is cancelled, then the answer is 204 and its events end with Cancelled by the sender.
- R3.2 Given a labelled shipment, when it is cancelled, then it is cancelled, and its label asked for afterwards is refused with 409.
- R3.3 Given a collected shipment, when it is cancelled, then the answer is 409, says that it is collected and that only one not yet collected can be cancelled, and it stays collected.
- R3.4 Given a cancelled shipment, when it is cancelled again, then the answer is 409 and nothing changes.
- R3.5 Given a subscription to shipment.status.changed, when a shipment of its account is cancelled, then one delivery says cancelled.
