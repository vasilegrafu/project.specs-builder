---
id: R5
name: List the shipments
priority: must
serves: G1
from: S2, the route at app.py:102; S3, GET /v1/shipments at openapi.json:23
---

When a program lists its account's shipments, Parcelpost shall answer them newest first, fifty to a page, with how many there are in all, kept to a status and to the sender's reference where the call names them.

## Accepted when

- R5.1 Given an account with 120 shipments, when page 3 is asked for, then the 20 oldest are answered and the total is 120.
- R5.2 Given three shipments with the reference VL-1047, when the list is asked for with that reference, then those three are answered and no other.
- R5.3 Given the status labelled, when the list is asked for with it, then only labelled shipments are answered.
- R5.4 Given an account with no shipments, when the list is asked for, then no item is answered and the total is 0.
- R5.5 Given a key without shipments:read, when the list is asked for, then the answer is 403.
