What a program calls Parcelpost with: it belongs to an account, carries its scopes, and is a test key or a live one.

## Fields

| Field | Meaning | From |
|---|---|---|
| account | whose shipments and subscriptions it reaches |  |
| scopes | some of shipments:read, shipments:write, labels and webhooks |  |
| test | whether its shipments are never collected and its labels say TEST |  |
