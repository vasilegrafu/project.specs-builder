id: N1
name: Shipment
---

One parcel a shop sends through Parcelpost: who sends it, to whom, by which service, and where it stands, from registered to delivered, returned or cancelled.

## Fields

| Field | Meaning | From |
|---|---|---|
| id | PP and twelve digits: on the label and the tracking page |  |
| status | created, labelled, collected, in_transit, out_for_delivery, delivered, returned or cancelled |  |
| service | standard, express or economy |  |
| sender, recipient | each an address: name, street, city, postcode, country, phone |  |
| parcel | its weight in kg, its length, width and height in cm, and what is in it |  |
| reference | the sender's own reference, an order number |  |
| events | every tracking event, oldest first |  |
| label | where the label's PDF is, once produced |  |
| account | whose it is: the account of the key that registered it |  |
