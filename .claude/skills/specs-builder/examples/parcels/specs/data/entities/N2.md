id: N2
name: Webhook subscription
---

An integrator's https address, the webhook events it asked for, and the secret that signs what it is sent; active until it fails ten tries in a row or is stopped.

## Fields

| Field | Meaning | From |
|---|---|---|
| id | WH and eight hexadecimal characters |  |
| url | the https address deliveries are sent to |  |
| events | shipment.status.changed, shipment.delivery.attempted, or both |  |
| secret | signs each delivery; answered once, when the subscription is made |  |
| active | whether it is sent anything |  |
| failures | its failed tries in a row |  |

## States

| State | Means | Moves to | Seen in |
|---|---|---|---|
| active |  | N2.active, N2.paused, N2.stopped | E37, E49, E52, E53, E54 |
| paused |  | N2.stopped | E37 |
| stopped |  |  | E37 |

## Lifecycle

| State | Event | Guard | Effect | Next |
|---|---|---|---|---|
| active | a try is answered 2xx within ten seconds | -- | its failures in a row are none again | active |
| active | a try fails | fewer than ten in a row | the delivery is tried again, B7 | active |
| active | the tenth try in a row fails | -- | it is sent nothing more, and what happens meanwhile is never sent | paused |
| active | the integrator stops it | -- | -- | stopped |
| paused | the integrator stops it | -- | -- | stopped |
| stopped | -- | -- | -- | -- |
