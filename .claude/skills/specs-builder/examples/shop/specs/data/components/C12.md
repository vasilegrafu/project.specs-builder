The pages of a list: each page's number, the one open marked, with Previous and Next.

## Parts

| # | Part | Kind | What it shows and does | States | Heard as | Component | Shows | About | Asks | Leads to |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | A page's number | link | Leads to SC2 at that page; the page open is marked and leads nowhere. | the one open marked | the page's number |  | R1 | E12 |  | SC2 |
| 2 | Previous | link | Leads to SC2 at the page before; not shown on the first. | not on the first page | Previous |  | R1 | E12 |  | SC2 |
| 3 | Next | link | Leads to SC2 at the page after; not shown on the last. | not on the last page | Next |  | R1 | E12 |  | SC2 |

## Variants

| Variant | When |
|---|---|
| default | the first page open |
| the last page | the last page open: no Next |

## Rules

- Under the list, centred; not shown when one page holds the list.
- The page open is marked, and its number is not a link.
