Where an order stands, in one word.

## Variants

| Variant | When |
|---|---|
| default | placed: confirmed, not yet paid |
| paid | the payment has cleared |
| shipped | it has left the warehouse |
| delivered | it has arrived |
| cancelled | cancelled by the customer or the admin |

## Rules

- The status's own word, as N3 names it, with a capital. (N3)
- One colour per status, the same on every screen.
