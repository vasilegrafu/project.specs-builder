---
id: C2
name: Secondary button
follows: FD1, FD2, FD3, FD5, FD6, FD9, FD10
---

An action beside the main one, or one that undoes: Sign up, Apply, Cancel this order, Change the password.

## Variants

| Variant | When |
|---|---|
| default | always, where the action can be taken |
| under the pointer | the pointer over it: a blue border and blue words |

## Rules

- White, with a grey border; it never competes with C1. (C1)
- An action that cannot be undone, such as Cancel this order, is a C2 with words that say so, never a C1. (C2, C1)
