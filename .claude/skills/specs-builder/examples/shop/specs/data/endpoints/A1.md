What a category page, a search and the home page's lists call: the products of a category or of a search, four to a page, in one of five orders.

## Who may call

| Caller | May | Else |
|---|---|---|
| anyone: U1, U2, U3 | list the products | nothing is refused: the catalogue is public |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| category | query | string: laptops, phones, audio, cameras, screens, accessories | no | one of the six categories, N1 |
| q | query | string: words to search the name and the description for | no | R3 |
| page | query | integer from 1 | no | four products to a page, as many pages as the products need, R1 |
| sort | query | string: featured, price-asc, price-desc, rating, newest | no | the five orders of the category page, R1 |

## Answers

| Status | When | Holds |
|---|---|---|
| 200 | always | the page's products, each with its slug, name, category, price and old price, stock state, rating, reviews, SKU, blurb and picture; the page, how many pages, how many products in all |

## Fails

| Status | When | Says |
|---|---|---|
| 200 | nothing matches the words | an empty page with total: 0 , which the search page shows as Nothing matches |

## Limits

| What | Is |
|---|---|
| Size | four products to a page |
| Idempotent | yes |
| Version | v1, in the path |

## Example

```http
GET /api/v1/products?category=laptops&page=1&sort=featured
```

```http
200 OK
Content-Type: application/json

{"items": [{"slug": "aero-14", "name": "Aero 14", "price": 1099.0, "oldPrice": 1249.0, "stock": "in"}], "page": 1, "pages": 2, "total": 6}
```
