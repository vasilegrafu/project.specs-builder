A cart placed: its lines, the delivery address, the way to pay, its total, and a status that moves from placed to delivered or ends cancelled.

| Field | Meaning | From |
|---|---|---|
| number | VL-1042: what the customer and the admin quote |  |
| date | the day it was placed |  |
| lines | the cart's lines as they were placed, each with its total |  |
| total | what was paid |  |
| status | placed, paid, shipped, delivered or cancelled |  |
| address | the delivery address given at the checkout |  |
| customer | whose it is; the admin sees the email |  |
