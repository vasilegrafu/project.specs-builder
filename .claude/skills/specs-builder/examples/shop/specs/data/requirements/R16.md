---
id: R16
name: A page for an address the shop does not have
priority: should
serves: G2
from: S2, an address that does not exist, V33
---

When anyone opens an address the shop does not have, the shop shall show a page of its own, in the shop's frame, that says so and offers the home page and the search.

## Accepted when

- R16.1 Given an address no page has, when it is opened, then the page shows the shop's header and footer, says that there is no page at that address, and offers the home page and the search.
- R16.2 Given the address of a product that no longer exists, when it is opened, then the same page shows.
