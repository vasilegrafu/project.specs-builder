---
id: R13
name: Move an order as the admin
priority: must
serves: G2
enforces: B3, B4
from: S2, the admin's orders and one order, V26 to V30; S3, PATCH /orders/{number}
---

When the admin opens the orders, the shop shall list every customer's order with the customer's email under the filters All, Open, Shipped and Cancelled with their counts, find one by number or email, and on an order offer the moves its status allows and a note to add.

## Accepted when

- R13.1 Given eight orders, when the admin opens Orders, then "All (8)" is chosen and the eight are listed with the customer's email; "Open (3)" lists the placed and the paid, "Shipped (4)" the shipped and the delivered, "Cancelled (1)" the cancelled.
- R13.2 Given a placed order, when the admin opens it, then Mark as paid and Cancel the order are offered; given a paid one, then Mark as shipped and Cancel the order; given a shipped one, then Mark as delivered; given a delivered or a cancelled one, then nothing.
- R13.3 Given a move the status does not allow, when it is asked of the shop, then it is refused and the order is unchanged.
- R13.4 Given a note typed, when Add is selected, then the note is kept on the order with who added it and when.
