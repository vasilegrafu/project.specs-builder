What the cart's code box calls: a discount code is applied in place of any before it.

## Who may call

| Caller | May | Else |
|---|---|---|
| U1, a visitor, by the session's cookie | apply a code to the session's cart | nothing is refused for who calls: a caller with no session is given one, and so a cart (E79) |
| U2, a customer signed in | apply a code to the account's cart | -- |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| code | body | string, 1 to 12 characters as typed | yes | four to twelve letters and digits once the spaces around it are taken off and it is put in capitals; run by the shop; not past its date, B5; one at a time, B4, R5 |

## Answers

| Status | When | Holds |
|---|---|---|
| 200 | the code passes | the cart, as A1 answers it, with the code applied, its percent and the amount taken off |

## Fails

| Status | When | Says |
|---|---|---|
| 422 | the code is not four to twelve letters and digits | {"detail": {"error": "a code is 4 to 12 letters and digits"}} |
| 422 | the shop runs no such code | {"detail": {"error": "that code is not known"}} |
| 422 | the code is past its date | {"detail": {"error": "AUTUMN5 expired on 30 November 2026"}} |
| 422 | the code is missing, empty, or longer than 12 characters as typed | the framework's list of what in the body is refused |

## Limits

| What | Is |
|---|---|
| Idempotent | yes: the same code applied again answers the same cart |
| Version | v1, in the path |

## Example

```http
POST /api/v1/cart/code
Cookie: session=<the shop's session>
Content-Type: application/json

{"code": "welcome10"}
```
