---
id: A4
name: Give the net in a gross price
kind: read
surface: vatkit.net(gross_price, country, category=None)
shows: R1, R4, R8
about: B1, B4, B5, B7
---

What a program calls for the price without its VAT, from the gross price; the VAT in it is the gross less this net.

## Who may call

| Caller | May | Else |
|---|---|---|
| U1, U3: any program that imports vatkit | ask the net in any gross price | nothing is refused for who calls: vatkit has no keys and no accounts |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| gross_price | argument | a Decimal, a whole number or a string of one: "119.00" | yes | never a float, never below zero, B1, B7, R8 |
| country | argument | string: a member state's two letters in either case | yes | a member state, EL for GR, B5, R1 |
| category | argument | string: books, food or medicine; or None | no | a category with a reduced rate in that member state; none for the standard rate, B4, R1 |

## Answers

| Status | When | Holds |
|---|---|---|
| returns | the amount, the member state and the category are taken | the net, a Decimal to the cent: the gross divided by one plus the rate; the gross less it is the VAT |

## Fails

| Status | When | Says |
|---|---|---|
| raises BadAmount | the amount is a float, is not a number, or is below zero | "0.1: give a Decimal, a whole number or a string, never a float" |
| raises UnknownCountry | the country is not a member state, or none | "CH is not a member state of the EU" |
| raises UnknownCategory | the member state has no reduced rate for the category | "DK has no reduced rate for books" |

## Limits

| What | Is |
|---|---|
| Version | the major version changes only when this function's name or what it takes changes (E70) |
| Idempotent | yes: the same call answers the same within one release |

## Example

```python
from vatkit import net

net("119.00", "DE")         # Decimal('100.00'); the VAT in it is 19.00
```
