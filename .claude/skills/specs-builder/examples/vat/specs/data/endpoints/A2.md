---
id: A2
name: Give the VAT on a net price
kind: read
surface: vatkit.vat_of(net_price, country, category=None)
shows: R1, R2, R8
about: B1, B4, B5, B7
---

What a program calls for the VAT on one net price in a member state, to the cent.

## Who may call

| Caller | May | Else |
|---|---|---|
| U1, U3: any program that imports vatkit | ask the VAT on any net price | nothing is refused for who calls: vatkit has no keys and no accounts |

## Takes

| Name | Where | Type | Required | Rule |
|---|---|---|---|---|
| net_price | argument | a Decimal, a whole number or a string of one: "100.00" | yes | never a float, never below zero, B1, B7, R8 |
| country | argument | string: a member state's two letters in either case | yes | a member state, EL for GR, B5, R1 |
| category | argument | string: books, food or medicine; or None | no | a category with a reduced rate in that member state; none for the standard rate, B4, R1 |

## Answers

| Status | When | Holds |
|---|---|---|
| returns | the amount, the member state and the category are taken | the VAT, a Decimal to the cent, half up: 19.00 on 100.00 in DE |

## Fails

| Status | When | Says |
|---|---|---|
| raises BadAmount | the amount is a float, is not a number, or is below zero | "0.1: give a Decimal, a whole number or a string, never a float" |
| raises UnknownCountry | the country is not a member state, or none | "CH is not a member state of the EU" |
| raises UnknownCategory | the member state has no reduced rate for the category | "DK has no reduced rate for books" |

## Limits

| What | Is |
|---|---|
| Version | the major version changes only when this function's name or what it takes changes (E70) |
| Idempotent | yes: the same call answers the same within one release |

## Example

```python
from vatkit import vat_of

vat_of("100.00", "DE")      # Decimal('19.00')
vat_of("0.05", "DE")        # Decimal('0.01'), 0.0095 half up
```
