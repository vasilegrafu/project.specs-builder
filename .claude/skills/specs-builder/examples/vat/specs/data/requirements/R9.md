When a person runs vatkit vat, gross, net, rate or check at the shell, vatkit shall print the answer of R2, R3, R4, R1 or R7, an amount as its country writes it and a rate as a percent, and end with 0.

## Accepted when

- R9.1 Given vatkit gross 100 DE, when it is run, then it prints 119,00 € and ends with 0.
- R9.2 Given vatkit net 119 DE --category books, when it is run, then it prints 111,21 €.
- R9.3 Given vatkit rate FI, when it is run, then it prints 25.5%; given vatkit rate DE --category books, it prints 7%.
- R9.4 Given vatkit check de123456789, when it is run, then it prints DE123456789.
- R9.5 Given vatkit vat 100 CH, when it is run, then it prints "vatkit: CH is not a member state of the EU" on the error stream, prints nothing else, and ends with 2.
