id: R6
name: Write an amount as its country writes it
priority: should
serves: G1
from: S1, money in money.py; S2, the test of money; S4, 2.2.0
---

When a program asks for an amount written for a member state, vatkit shall write it to the cent with that country's marks for the thousands and the cents and the euro sign where that country puts it, and as €1,234.50 for any other country or none.

## Accepted when

- R6.1 Given 1234.5 for DE, when it is written, then it reads 1.234,50 €; for AT, IT and ES the same.
- R6.2 Given 1234.5 for NL, when it is written, then it reads €1.234,50.
- R6.3 Given 1234.5 for FR, when it is written, then it reads 1 234,50 €, with a narrow space for the thousands.
- R6.4 Given 1234.5 for IE, for PL, or for no country, when it is written, then it reads €1,234.50.
- R6.5 Given 0.125 for DE, when it is written, then it reads 0,13 €.
- R6.6 Given an amount that R8 refuses, when it is written, then it is refused in the same words.
