Start Claude Code

What you need

  • Claude Code, an AI assistant that works on the files on your computer. You talk to it in ordinary sentences.
  • Python, which the small website needs to run. You won't have to write any.
  • A browser.

SETUP.md says how to get them. You also need the specs-builder skill, a set of instructions that teaches Claude this job.

Do this

  1. Make a new empty folder, and call it bakery.
  2. Open a terminal there. A terminal is a window where you type. On Windows, open the folder in File Explorer, click the address bar, type powershell and press Enter. On a Mac, open Terminal, type cd and a space, drag the folder in, and press Enter.
  3. Type claude and press Enter.

What you see

A prompt where you can type sentences. From now on, you just talk to it. If you prefer, Claude Code also comes as a desktop app.

Why it matters

Everything Claude makes stays in this folder, on your computer. You can close the window and come back next week: the work is in the folder, not in the conversation.

If yours looks different

If claude isn't found, it isn't installed yet: see SETUP.md. Claude may ask for permission before it does things. That's normal, and you can say no.
